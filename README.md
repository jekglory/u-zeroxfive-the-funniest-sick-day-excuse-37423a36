One sick-day excuse a real person could text their boss: a stiff neck from sleeping wrong leaves the sender able to look left only, so the commute would be one very long U-turn. Half believable, fresh, and the twist lands near the end.

## Run it

```sh
python3 main.py
```

The program writes the line (122 characters, one line) to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else for a local run. Pure Python standard library, no third-party packages; two runs produce byte-identical output.
